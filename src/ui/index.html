Поведение панели

WINDOWS

Настройки сохраняются в Windows и работают после закрытия MagmPaper.

Применяются только изменённые пункты. Скрытие работает сразу; остальным настройкам может потребоваться повторный вход в Windows. Защищённые параметры (например, виджеты на некоторых сборках) меняются через «Открыть параметры Windows». Отказ для одного пункта не отменяет остальные.

Экономия ресурсов

Полноэкранное или развёрнутое окно на основном мониторе останавливает рендер и опрос мыши. После сворачивания обои продолжат работу.

Обои возобновятся после подключения питания. При блокировке Windows пауза включается автоматически.

Ниже частота — меньше нагрузка. Качество 50% уменьшает число пикселей в четыре раза, но делает изображение мягче. Размер обоев на экране не меняется.

Изменения сохраняются сразу и применяются к рабочему столу. На паузе кадры не рисуются; память сохраняется для быстрого продолжения.
