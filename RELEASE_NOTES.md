MagmPaper 0.3.0 — встроенное оформление стандартной панели Windows.

Полностью закройте MagmPaper через трей → «Выход» и установите MagmPaper-Setup-0.3.0.exe поверх прежней версии. Обои, настройки приложения и резервные значения панели сохраняются. Windhawk для новых возможностей не требуется: собственный модуль входит в установщик и ZIP, скачивать или устанавливать его отдельно не нужно.

В разделе «Панель задач → Оформление панели» доступны:

- Высота панели, размер значков приложений и ширина кнопок.
- Цвет фона, непрозрачность от 0 до 100% и скругление фона.
- Скрытие кнопки виджетов без записи защищённого параметра TaskbarDa.
- Готовые наборы размеров и возврат исходного оформления Windows.

Сохраняется именно стандартная панель Windows — её трей, закреплённые приложения и меню. Оформление включается по желанию, действует также в трее и восстанавливается при следующем запуске MagmPaper. Полный выход возвращает исходный вид. Для запуска вместе с Windows включите соответствующий пункт в общих параметрах.

Если в Windhawk уже включены моды Taskbar height and icon size или Windows 11 Taskbar Styler, отключите их перед включением оформления MagmPaper. Удалять сам Windhawk необязательно.

Защищённый переключатель виджетов заменён настройкой видимости кнопки в собственном модуле. Включение самой функции виджетов остаётся в параметрах Windows. Настройки поведения панели и все функции GLSL-обоев сохранены.

Модуль работает по событиям, без постоянного опроса панели. Проверки выполняются только при подключении и применении настроек. Сборки Windows с несовместимой XAML-панелью показывают ошибку подключения, не сохраняют неприменённое оформление и не останавливают обои.

Автотесты проверяют реальные XAML-элементы в изолированном окне Windows, подключение DLL, откат после сбоя, повторное подключение, интерфейс, а также установку и обновление с сохранением данных. Проверка в изолированном окне не заменяет проверку внешнего вида настоящей панели на каждой сборке Windows 11; после системных обновлений совместимость может меняться. Установщик пока без цифровой подписи.
