MagmPaper 0.1.5 для Windows 11 x64.

- Исправлена ложная автопауза при видимом рабочем столе: служебные, неактивируемые и прозрачные полноэкранные поверхности больше не считаются перекрывающими приложениями.
- Окно самих обоев явно исключено из проверки.
- Проверка учитывает порядок окон: окна под поднятым рабочим столом (Win+D) не вызывают паузу.
- Настоящее полноэкранное или развёрнутое окно по-прежнему приостанавливает обои. После сворачивания или уменьшения окна анимация возобновляется при следующей проверке (до секунды).
- Добавлены регрессионные проверки ложной паузы, возобновления анимации и Windows API.

Завершите старую версию через трей → «Выход», распакуйте MagmPaper-0.1.5-win.zip и запустите MagmPaper.exe. При смене папки обновите настройку автозапуска. Коллекция и параметры сохраняются.
