MagmPaper 0.4.2 — нативное приложение для Windows 11 x64.

Исправлено применение тёмной темы главного окна и наследование цвета текста. Контраст заголовков и кнопок теперь также проверяется в настоящем WPF-интерфейсе.

Интерфейс и логика перенесены на C# / WPF / .NET 10 LTS. Chromium, Electron, HTML и JavaScript больше не входят в приложение. Существующие GLSL-обои работают через OpenGL ES 2.0 / ANGLE / Direct3D 11; переписывать коллекцию не нужно. Собственный C++-модуль стандартной панели Windows сохранён.

Сохранены коллекция с отдельными GLSL-файлами, редактор и предпросмотр, плавная реакция на мышь, трей, автозапуск, FPS и качество, автоматическая пауза, восстановление после смены разрешения и сброса GPU, поведение и оформление панели задач. В интерфейсе есть обзор, коллекция, параметры панели с наглядным предпросмотром и общие настройки. Для будущих разделов используется единая навигация и стили WPF.

Скрытый предпросмотр и обои на паузе не рисуют кадры и не опрашивают мышь. Курсор считывается вместе с кадром без отдельного частого опросчика. Нативные GPU-команды двух поверхностей согласованы; восстановление проверяется с активным и приостановленным предпросмотром. Реальная нагрузка зависит от шейдера, разрешения, настроек и видеокарты.

Для обновления полностью закройте прежнюю версию через трей → «Выход» и запустите **MagmPaper-Setup-0.4.2.exe**. Установщик удалит прежние программные файлы, сохранит `%APPDATA%\MagmPaper` и существующую настройку автозапуска. Устанавливать .NET, Node.js или Windhawk отдельно не нужно. Приложение запускается через ярлык. В ZIP включены те же компоненты; архив нужно полностью распаковать в отдельную папку.

Коллекция, выбранные обои, параметры производительности, оформления и резервные значения панели остаются совместимыми. При первом нативном запуске создаётся дополнительная копия `wallpapers.json.electron-backup`. Удаление приложения также сохраняет пользовательскую коллекцию.

Проверки Windows включают настоящий WPF-интерфейс и чтение пикселей GLSL, backbuffer, ошибки компиляции, паузу, курсор, геометрию и перекрытие окон, повторное восстановление GPU, C++/XAML-модуль панели, обновление с опубликованной версии 0.3.1, ярлыки, повторную установку и удаление с сохранением данных. GPU в CI — программный D3D11 WARP. Снимок интерфейса и отчёт приложены к релизу; они не заменяют проверку конкретного драйвера и настоящей панели Explorer на целевом ПК.

Приложение рассчитано на основной монитор. Совместимость модуля панели зависит от сборки Windows 11. Установщик пока без цифровой подписи.
