MagmPaper 0.2.1 — исправление применения настроек панели задач.

Закройте MagmPaper через трей → «Выход» и установите MagmPaper-Setup-0.2.1.exe поверх старой версии. Коллекция GLSL-обоев, настройки приложения и резервные значения панели задач сохраняются.

- Исправлено: попытка записать защищённый параметр виджетов TaskbarDa отменяла изменения остальных пунктов группы Windows.
- Теперь записываются только изменённые пункты. Неизменённые настройки не затрагиваются, в том числе если Windows защищает их от записи.
- Ошибка одного пункта не отменяет остальные. Приложение отдельно сообщает, что сохранено и что Windows запретила, затем показывает фактические значения переключателей.
- Запись выполняется напрямую через Win32 API: вместо нечитаемого вывода reg.exe отображается понятное сообщение с названием настройки.
- Возврат исходных значений также работает по отдельным пунктам. Неизменённые защищённые значения из резервных копий 0.2.0 пропускаются; значения неудачных восстановлений остаются для повторной попытки.

Защищённые Windows параметры меняйте через «Открыть параметры Windows». Приложение не обходит защиту реестра. Если сохранённые расположение кнопок или поиск ещё не изменились визуально, выйдите из учётной записи Windows и войдите снова. Скрытие панели применяется сразу.

Раздел размеров через Windhawk не изменён. Функции обоев сохранены.

Проверяются отказ в доступе, независимое применение и восстановление настроек, интерфейс при частичном успехе, реальные операции реестра Windows и обновление установщика с сохранением коллекции. Установщик пока без цифровой подписи; также доступна ZIP-сборка.
