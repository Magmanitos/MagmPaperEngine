Первая версия MagmPaper для Windows 11 x64.

- Локальная коллекция GLSL-обоев: добавление кода, сохранение, редактирование и удаление.
- Предпросмотр WebGL и отображение ошибок компиляции.
- Поддержка time, resolution, mouse, backbuffer и стандартных производных GLSL.
- Установка на основной монитор, остановка и управление через трей.

Скачайте MagmPaper-0.1.0-win.zip, полностью распакуйте его и запустите MagmPaper.exe. Node.js и IDE для запуска сборки не нужны. Приложение не подписано цифровой подписью.

Для разработки нужны Visual Studio Code и Node.js 24 LTS: npm ci, затем npm start.

Проверены тесты хранения данных и браузерные сценарии с настоящим WebGL. Размещение за значками через WorkerW пока не проверено на реальном рабочем столе Windows 11; его совместимость зависит от версии Explorer. Поддерживается основной монитор, 30 FPS. Подробности — в README.md.
