MagmPaper 0.2.0 — обои и персонализация Windows в одном приложении.

Скачайте MagmPaper-Setup-0.2.0.exe. Закройте старую версию через трей → «Выход» и установите обновление поверх неё. Установщик заменяет файлы программы; добавленные GLSL-обои, выбор, настройки и автозапуск сохраняются. Отдельно удалять прежнюю версию не нужно.

- Новый интерфейс: «Обзор», «Обои», «Панель задач» и общие параметры. Меню подготовлено для новых разделов персонализации.
- Все функции обоев сохранены: коллекция отдельных GLSL-файлов, папка в Проводнике, редактор, предпросмотр, реакция на мышь, автозапуск и восстановление после смены разрешения.
- Панель задач: выравнивание, поиск, виджеты, представление задач и автоматическое скрытие. Для некоторых настроек Windows потребуется выйти из учётной записи и войти снова.
- Размеры панели, значков и кнопок, три пресета и ручная настройка. Для этой группы нужен отдельно установленный Windhawk с включённым модом Taskbar height and icon size: https://windhawk.net/mods/taskbar-icon-size. Поддерживается обычная установка с общей конфигурацией мода. Windhawk должен работать; применение размеров требует подтверждения запроса администратора Windows. Компонент не устанавливается автоматически и не включён в установщик.
- Исходные настройки сохраняются перед первым изменением; кнопки «Вернуть исходные» возвращают их. Настройки Windows/Windhawk продолжают действовать после закрытия или удаления MagmPaper.
- Предпросмотр перестаёт рисовать кадры вне раздела «Обои». Новый раздел не добавляет постоянного опроса или фоновых таймеров; ограничения FPS, разрешения и автоматическая пауза обоев сохранены.

Проверяются интерфейс с реальным WebGL, сохранение и восстановление настроек, нативный API Windows, запись параметров мода в изолированной ветке реестра, обновление старой версии и сохранность коллекции после удаления. Визуальная работа стороннего мода Windhawk в CI не проверяется.

Установщик пока без цифровой подписи. Также доступна ZIP-сборка.
