MagmPaper 0.1.2 для Windows 11 x64.

- Добавлена реакция GLSL-обоев на движение мыши на рабочем столе через uniform vec2 mouse.
- Координаты обновляются до 30 раз в секунду с учётом масштаба Windows и положения монитора.
- Окно обоев пропускает клики: значки и меню рабочего стола остаются доступны.
- При остановке, замене обоев и переходе в сон опрос курсора прекращается.

Шейдер должен использовать переменную mouse. Шейдеры, которые её не используют, сохранят прежнее поведение (включая встроенное «Северное сияние»).

Полностью завершите предыдущую версию через трей → «Выход». Распакуйте MagmPaper-0.1.2-win.zip и запустите MagmPaper.exe. При смене папки повторно включите автозапуск.
