MagmPaper 0.1.6 — установочная версия для Windows 11 x64.

Скачайте MagmPaper-Setup-0.1.6.exe. Полностью закройте старую версию через трей → «Выход» и запустите установщик. После установки запускайте MagmPaper ярлыком на рабочем столе или в меню «Пуск». Node.js, npm, VS Code и подключение к интернету для установки и запуска не нужны.

- Мастер установки с выбором папки. Папка по умолчанию: %LOCALAPPDATA%\Programs\MagmPaper.
- Собственная иконка приложения, ярлыков и трея.
- Все необходимые компоненты входят в установщик.
- Данные хранятся отдельно: %APPDATA%\MagmPaper\wallpapers.json. При первом запуске импортируется старая коллекция из %APPDATA%\magmpaper-engine, если новой библиотеки ещё нет. Исходный файл сохраняется.
- Существующая запись автозапуска переносится на установленный EXE. Для новой установки автозапуск включается только в параметрах приложения.
- Повторная установка сохраняет данные. Удаление через параметры Windows убирает программу, ярлыки и её автозапуск, сохраняя коллекцию в AppData.
- Возможности обоев и исправления автопаузы из 0.1.5 сохранены.

Также приложен ZIP для ручной распаковки. Для обычной установки выбирайте файл Setup.exe.

Установщик пока не имеет цифровой подписи, поэтому Windows может предупредить о неизвестном издателе.
