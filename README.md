# MagmPaper

Минималистичные живые GLSL-обои для **Windows 11 x64**. Добавляйте фрагментные шейдеры с glslsandbox.com, сохраняйте их в коллекцию и устанавливайте на основной монитор. Есть встроенный пример, предпросмотр, редактирование, удаление, остановка и значок в трее.

## Запуск и IDE

Скачайте **Visual Studio Code** (https://code.visualstudio.com/) и **Node.js 24 LTS** (https://nodejs.org/). Полная Visual Studio не нужна.

Откройте папку проекта в VS Code. В меню «Терминал → Создать терминал» выполните:

```powershell
npm ci
npm start
```

Команды выполняются из папки с `package.json`. Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd ci` и `npm.cmd start` или терминал Command Prompt; менять политику выполнения не нужно.

Для установщика:

```powershell
npm run dist
```

Результат — `dist/MagmPaper Setup 0.1.1.exe`. Установщик пока без цифровой подписи: Windows может показать предупреждение об неизвестном издателе. Для готового установщика Node.js и IDE не требуются.

Для ZIP-версии выполните `npm run dist:zip`. Полностью распакуйте архив в отдельную папку и запустите `MagmPaper.exe`; остальные файлы рядом с ним обязательны.

## Как пользоваться

1. Откройте шейдер на glslsandbox.com и скопируйте **весь код фрагментного шейдера** из редактора сайта.
2. Нажмите «Добавить обои», задайте название и вставьте код.
3. Нажмите «Проверить»: ошибки компиляции появятся под редактором. После проверки нажмите «Сохранить».
4. Выберите обои в коллекции и нажмите «На рабочий стол». Значки рабочего стола остаются доступными.
5. Кнопка «Остановить обои» возвращает обычный фон Windows. Удаление активных обоев тоже останавливает их.

Закрытие окна сворачивает приложение в трей. Двойной щелчок по значку открывает библиотеку. Для полного завершения выберите «Выход» в контекстном меню трея. При следующем запуске приложения последние выбранные обои восстанавливаются. В боковой панели включите «Запускать с Windows»: при входе в систему приложение запустится в трее и восстановит последние установленные обои. Если Проводник ещё загружается, приложение подождёт его готовности. Кнопка «Остановить обои» очищает выбор для следующего запуска.

Автозапуск работает и при разработке через `npm start`. Он привязывается к текущему пути приложения: после переноса проекта или ZIP-сборки выключите и снова включите переключатель из нового расположения.

Данные: `%APPDATA%/magmpaper-engine/wallpapers.json` (в сборке имя каталога может зависеть от имени приложения Electron). Скопируйте файл для резервной копии. Приложение сохраняет изменения атомарной заменой файла; повреждённая библиотека не перезаписывается. Ошибка открытия показывает точный путь.

## Совместимость и ограничения первой версии

- WebGL 1 / GLSL ES 1.00: `time` — секунды, `resolution` — размер рендера в пикселях, `mouse` — координаты 0…1, `backbuffer` — предыдущий кадр. Есть `varying vec2 surfacePosition` в диапазоне −1…1.
- На предпросмотре мышь интерактивна. На рабочем столе `mouse` фиксирована в центре, чтобы окно обоев не перехватывало клики по значкам.
- Поддерживаются самодостаточные фрагментные шейдеры без внешних текстур. Shadertoy `mainImage`, GLSL 300, внешние изображения/звук и дополнительные проходы требуют адаптации. Ссылки не импортируются: вставляйте именно код.
- Основной монитор, 30 FPS, ограничение размеров текстур до 3840 пикселей по каждой оси; сложные шейдеры могут сильно нагружать GPU.
- Обои подключаются к слою Explorer WorkerW через Win32 API. Этот механизм не документирован Microsoft и может измениться после обновления Windows. Если Explorer перезапустится, повторно нажмите «На рабочий стол».
- Предпросмотр при скрытом окне приостанавливается. При сне обои освобождаются и восстанавливаются после пробуждения. Автоматическая пауза для полноэкранных игр пока отсутствует.
- Renderer изолирован: без Node.js, без сетевого доступа через CSP. Код пользователя передаётся только компилятору GLSL; JavaScript из него не исполняется.

## Проверки

```powershell
npm test
```

Автотесты проверяют сохранение/редактирование/выбор/удаление, восстановление библиотеки, некорректные данные и сбой записи. Проверка реального рабочего стола требует Windows 11 и GPU-драйвера:

- Установить встроенный пример; убедиться, что анимация **за значками**, значки открываются, а в Alt+Tab нет окна обоев.
- Добавить шейдер с glslsandbox.com, проверить ошибку GLSL, сохранить исправленный код и переключить обои.
- Закрыть/открыть окно через трей; проверить остановку, удаление активных обоев и сохранность коллекции после полного выхода.
- Проверить основной монитор с масштабом 100%/150%, сон/пробуждение и перезапуск Explorer.

`npm run test:windows` проверяет реальное окно Electron (размеры клиентской области и начало координат) и включение/выключение автозапуска с отдельной временной записью реестра. Это не заменяет проверку реального Explorer после входа в Windows.

Linux подходит для тестов библиотеки и WebGL-предпросмотра. Интеграция WorkerW на Linux недоступна; успешная сборка не заменяет проверку Windows.

Дополнительная проверка интерфейса: `npm run test:ui`. Нужен Chromium; путь задаётся переменной `CHROMIUM_PATH` (по умолчанию `/usr/bin/chromium`). Тест проверяет реальные пиксели WebGL, накопление `backbuffer`, ошибки GLSL и действия с библиотекой. Win32-вызовы в этом тесте не выполняются.

Для кросс-сборки ZIP на Linux перед `npm run dist:zip` потребуется `npm install --force --ignore-scripts --no-save @koromix/koffi-win32-x64@3.3.6`: это добавляет целевой Windows-модуль Koffi; `--force` разрешает его установку на другой ОС. На Windows достаточно обычного `npm ci`. NSIS-установщик на Linux дополнительно требует Wine.
